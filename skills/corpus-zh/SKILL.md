# corpus-zh

语文作文语料库的执行 SOP。**规范源是 `PROMPT.md`，不要改。**

```bash
CORPUS=/var/minis/mounts/7A84464D-AA03-41E8-A2F3-C38F2CA047D0/知识库/语文语料库
INTAKE=/Note/语文                   # 投料口（iOS 文件 App 里的 Note/语文）
```

## 判据不是英语那套

英语用 What→How→Effect→Value，**语文用老师的六维**：

概念界定 → 段首句 → 机制 → 论据 → 思路 → 深化

> 老师原话：「前一维未立，后一维无所依附。」

**不要套用英语的四段式。** 两个库的判据不同，混用会毁掉语文库的评分价值。

## 只收三类

1. 你自己写、被老师圈 ✓ 的原句
2. 老师给的机制 / 修改示例
3. 避坑（老师指出的病灶）

其余进素材池，标淘汰理由。**不要为了凑数收录平淡的句子。**

## 投料目录约定

```
/Note/语文/
├── 第二次呼吸/
│   ├── 《第二次呼吸》一稿（姜川）20260927.pages
│   ├── 《第二次呼吸》二稿（姜川）20260927.pages
│   └── 《第二次呼吸》二稿批阅单（姜川）20260927.pdf
└── 说论辩/ …
```

1. **一题一文件夹**，文件夹名 = 题目本身，不加编号、不加空格后缀
2. 文件名统一 `《题目》稿次（姜川）YYYYMMDD.扩展名`
3. `X 2` 这类重复文件夹是 iOS 拷贝冲突：先 `md5sum` 比对，相同的删掉，独有的并回主文件夹
4. **原件不搬走**（用户还要在 Pages 里改）

## 流程

### 1. 读料

- `.pages` 的文字**不在** `Document.iwa` 里，正文只在 `preview.jpg`
  → 解压 zip 后读图：`apple-vision ocr --source preview.jpg`
- `.pdf` 批阅单直接读文本或 OCR

### 2. 入库

`corpus/<编号>-<题目>.md`，结构对齐现有的 00~03 号文件。

写清：一稿分数 → 二稿分数、分数变化的原因、老师原话引用。

### 3. 提炼跨篇病灶

如果发现**两篇以上共有的问题**，写进 `corpus/00-跨篇通用招法.md`。

已知的两条：
- **题眼未对接**：用自己的核心词替代题目的词
- **首尾不回扣**：拆了要素，升华段没把结论收回来

### 4. 复习队列

`REVIEW/recall-queue.md`，格式与 due.sh 解析规则一致（见 `REVIEW/due.sh`）。

```bash
TODAY=$(date +%F) sh "$CORPUS/REVIEW/due.sh"
```

- 每次 3 条
- 中英对照不适用（这里是中文），**给原句 + 出处 + 一句提示**
- 手动触发，不要建定时任务
